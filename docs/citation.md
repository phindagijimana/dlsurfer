# Citation

Always cite **upstream engines**, not DLSurfer as a morphometry method.

```bash
dlsurfer cite --profile core-lesion
```

Full per-engine resources and papers: **[Methods — engines](methods/engines.md)** (generated from `engines.yaml`).

Typical `core-lesion` stack:

- Henschel et al., FastSurfer (NeuroImage 2020; VINN 2022)  
- Pollak et al., FastSurfer-LIT (Imaging Neuroscience 2025)  
- Faber CerebNet; Estrada HypVINN; Hoopes SynthStrip / TopoFit  
- Fischl, FreeSurfer (NeuroImage 2012) for classical surfaces
