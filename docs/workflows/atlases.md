# Atlases

DKT is the **default** labeling scheme (FastSurfer deep DKT). DK / Destrieux / Schaefer are in-scope via flags and profiles — see [reference/ATLASES.md](../reference/ATLASES.md).

```bash
dlsurfer atlases
dlsurfer run --profile core --atlas dk ...
dlsurfer run --profile atlas-destrieux ...
```
